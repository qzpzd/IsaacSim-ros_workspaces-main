# Linux端连接远程Windows Isaac Sim使用指南

## 环境配置（已完成）
- ROS2 Humble
- CycloneDDS (rmw_cyclonedds_cpp)
- ROS_DOMAIN_ID=0

## Windows端要求
确保Windows端的Isaac Sim使用相同配置：
- DDS类型: CycloneDDS
- ROS_DOMAIN_ID=0
- 防火墙允许UDP通信（端口7400-7401）

## 使用方法

### 1. 快速启动连接脚本
```bash
cd /home/star/qzp/IsaacSim-ros_workspaces-main/humble_ws
./connect_to_windows_isaac.sh
```

### 2. 手动配置环境
```bash
# 源ROS2环境
source /opt/ros/humble/setup.bash

# 源工作空间
source install/setup.bash

# 设置环境变量（必须与Windows端一致）
export ROS_DOMAIN_ID=0
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
```

### 3. 测试连接
```bash
# 查看话题列表
ros2 topic list

# 查看节点列表
ros2 node list

# 查看服务列表
ros2 service list
```

## 常用命令

### 查看话题信息
```bash
# 查看话题类型
ros2 topic info /topic_name

# 监听话题数据
ros2 topic echo /topic_name

# 发布话题数据
ros2 topic pub /topic_name geometry_msgs/msg/Twist "{linear: {x: 0.5}}"
```

### 查看节点信息
```bash
# 查看节点详情
ros2 node info /node_name
```

## 故障排查

### 无法连接到远程Isaac Sim
1. 检查Windows端Isaac Sim是否已启动并加载ROS2 bridge
2. 检查防火墙设置，确保允许UDP通信
3. 确认两台机器在同一网络中
4. 检查ROS_DOMAIN_ID是否一致

### 只看到基本话题(/parameter_events, /rosout)
- 这表示ROS2网络正常，但Isaac Sim的ROS2 bridge还未激活
- 确保在Isaac Sim中使用了正确的启动参数：
  ```
  isaac-sim.bat --/isaac/startup/ros_bridge_extension=isaacsim.ros2.bridge
  ```

### 更换DDS类型
如果需要使用FastDDS而不是CycloneDDS：
```bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export FASTRTPS_DEFAULT_PROFILES_FILE=/home/star/qzp/IsaacSim-ros_workspaces-main/humble_ws/fastdds.xml
```

## 注意事项
- 每次打开新终端都需要重新配置环境变量
- 确保Linux和Windows使用相同的ROS_DOMAIN_ID和DDS类型
- 对于长时间运行的任务，建议使用tmux或screen保持会话
